# Prospective exploratory head/objective control

Fixed before follow-up GPU training on 4 October 2026. This study tests a bounded explanation for the earlier small-S4 residual error, without requiring either head to win. Earlier primary and sensitivity results are preserved. This is a follow-up to observed results, not the original preregistered comparison.

**Question:** with identical full normalized history information and comparable validation tuning, does temporal S4 differ from AdaLN MLP, and does equal weighting of velocity directions change the difference?

**Data:** fresh independent synthetic GP splits, seed 67041 (+0/+1/+2 for train/validation/test), RBF lengthscale 8, lookback 32, horizon 16, variance 1, nugget 1e-6. There are 32,768/4,096/8,192 windows and 1,024 generated paths per final cell. Existing history-only Sundial normalization and independent raw-kernel GP source apply. Validation must pass the original nonempty geometry and GP-velocity top-two >90% gate. PCA is fit on training velocities only. Test data are not generated or inspected during pilots.

**Controlled factors:** MLP versus genuine three-block S4; raw MSE versus PCA-weighted error. Both receive the same exact normalized 32-point history through an identity encoder, with no learned representation. Existing width 56 and S4 state size 16 are retained. Both inputs and predicted velocities remain in temporal observation coordinates. The balanced objective is mean((error @ Q.T / scales)^2), with scales = sqrt(max(training eigenvalue, max(1e-6*leading eigenvalue,1e-8))). This changes loss weighting only; no S4 convolution runs over principal-component indices. It does not remove other architectural differences, including absolute-position access.

**Validation-only tuning:** each of four head/objective cells receives exactly two learning-rate pilots, 0.001 and 0.0003, seed 20, 4,000 updates each. Save the best validation objective every 500 updates. Each cell chooses its own rate by its own objective (ties choose smaller rate). All eight pilots must finish and the complete selection file must be locked before any final test evaluation. No pilot test metrics or generated test paths are computed. Objectives of different loss types are not numerically compared to select a winner.

**Final runs:** seeds 10, 11 and 12; 8,000 updates at the selected rate; AdamW, batch 256, weight decay 1e-4 except existing SSM no-decay parameters, gradient clipping 1.0, and best validation checkpoint every 500 steps. No schedule or early stopping. Reseeding after model construction pairs examples, source normals and flow times across heads/objectives for each seed. Euler uses 64 steps for every final model. No test-based extension or model selection.

**Reporting:** all 12 final runs and eight pilots, parameter counts, runtime, validation curves, selected rates, per-PC raw/normalized velocity errors, five time-bin diagnostics, and generated roughness. Apply the original formal success flag unchanged as a reported diagnostic, while explicitly preserving its known anisotropic-equality limitation. Pair differences by optimization seed and disclose only three seeds and one new GP data draw. Do not extrapolate to published full-scale TSFlow/Sundial or long-sequence S4. Save source hashes, configs, checkpoints, samples and selection record for audit. Every planned result is retained, including poor balanced-loss outcomes.
